# Fabrica de Fotolibros

## Project Overview
Fabrica de Fotolibros is a web application that allows users to design and create custom photobooks and other products online. Users can access the platform without needing to install any software; all they need is to be registered and logged into the system. The application provides a clean interface for users to design their products seamlessly.

## Installation
To run this project locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/fabrica-de-fotolibros.git
    ```

2. **Navigate to the project directory**:
    ```bash
    cd fabrica-de-fotolibros
    ```

3. **Open `index.html` in your browser**:
   Simply double-click the `index.html` file or open it via your web browser's file menu.

## Usage
Once you open the application in your browser, you will see the main interface with the option to scroll and learn more about designing your photobook. Click on the "Entrar" button to log in or sign up (only the button functionality is represented here, as the underlying login system is not included in this repository).

## Features
- User-friendly design interface for creating custom photobooks.
- Responsive design that adapts to various screen sizes.
- Simple and intuitive navigation with clearly labeled sections.

## Dependencies
No explicit dependencies are defined in the project as it primarily consists of HTML and CSS. The project is standalone and does not rely on external libraries or frameworks.
